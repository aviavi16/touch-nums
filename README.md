# Touch the Numbers (touch-nums)
![Touch Numbers Preview 5](https://github.com/user-attachments/assets/9d17d84c-448c-4fbf-ae91-fe2ae27c506c)
## About the Project

**Touch the Numbers** is an interactive and engaging game designed to help players improve their number recognition skills by clicking numbers in sequence. The game starts with a shuffled board of numbers, and the player must click them in order from 1 to the highest number.

This project originated from an exercise in my Fullstack course at **Coding Academy**, led by **Yaron Biton**, a former tech training commander in the **Mamram department of the IDF**. However, I took this simple exercise and expanded it into a full-fledged game, making it much more interactive and visually appealing.

## Features

- **Interactive Number Clicking**: Players click numbers in the correct order to progress.
- **Dynamic Board Sizes**: Choose different difficulty levels with increasing grid sizes (4x4, 5x5, 6x6, etc.).
- **Game Timer**: The game starts timing when the first number is clicked and displays the result with millisecond precision.
- **Visual and Audio Enhancements**:
  - **CSS Animations** for smooth transitions and effects.
  - **Sound Effects** for user feedback and engagement.
  - **High-Quality UI Design** with feedback from professional designers and artists.
- **Built with React**: The original JavaScript and HTML exercise was upgraded to use **ReactJS**, making the game more scalable and maintainable.
- **Responsive Design**: Fully functional across different screen sizes and devices.

## Motivation

I decided to expand this project to create an engaging and fun way for my child to learn numbers. Instead of just following the exercise, I incorporated modern UI/UX principles, animations, and sound design to make the experience immersive and educational.

## How to Play

1. Choose a difficulty level (grid size).
2. Click the numbers in order, starting from 1.
3. The game timer starts when the first number is clicked.
4. Clicking the correct number changes its color and advances the game.
5. Complete the sequence as fast as possible to get your best time!

## Installation and Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/touch-nums.git
   ```
2. Navigate to the project directory:
   ```sh
   cd touch-nums
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm start
   ```
5. Open your browser and go to `http://localhost:3000/` to play!
